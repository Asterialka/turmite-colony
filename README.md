# Колония турмитов

Программа на C показывает, как 32 турмита движутся по общему замкнутому полю и оставляют шестицветные следы.

## Запуск

Нужны компилятор C с поддержкой C11, `make`, `pkg-config` и SDL2 с заголовочными файлами. В каталоге проекта выполните:

```sh
make
./turmites
```

Чтобы остановить программу, закройте окно. Размер окна — 1536 × 768 пикселей.

## LLVM IR

Оптимизированный LLVM IR для логики программы уже лежит в `app-opt.ll`. Если нужно пересоздать его из `app.c`, установите `clang` и выполните `make -B ir`.
